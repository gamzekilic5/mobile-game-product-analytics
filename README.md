# Mobile Game Product Analytics & A/B Testing

## Project Overview

This project simulates a real-world mobile game product analytics case.

The objective is to evaluate whether a new **Daily Reward System** improves player behavior and overall product performance.

Players are randomly assigned to two groups:

- **Control Group (A):** Players receive a standard daily reward.
- **Treatment Group (B):** Players receive a progressive reward based on consecutive daily activity.

The analysis focuses on understanding whether the new feature creates a meaningful improvement in player retention and engagement without negatively affecting monetization.

## Business Question

**Does the new Daily Reward System improve player retention and engagement compared with the existing reward system?**

## Key Metrics

The experiment will evaluate:

- D1 Retention
- D7 Retention
- Session Frequency
- Average Playtime
- Level Progression
- Conversion Rate
- ARPU (Average Revenue Per User)

## Project Workflow

1. Generate a simulated mobile game player dataset
2. Explore player behavior and data quality
3. Analyze product and engagement metrics
4. Compare Control and Treatment groups
5. Perform statistical hypothesis testing
6. Calculate confidence intervals and effect sizes
7. Analyze player segments
8. Evaluate retention and monetization trade-offs
9. Derive product insights
10. Make a data-driven product recommendation
